# spring-boot-lab8

Лабораторная работа №8 по дисциплине «Технологии программирования».
Выполнил: Урабов Николай Михайлович, группа РИЗ-250213у.

Веб-приложение «Учёт студентов» со Spring Security: регистрация, вход по email и паролю,
роли пользователей. Spring Boot 4.1.2, Java 25, Spring Security, Spring Data JPA, H2, Thymeleaf, Lombok.

## Запуск

Запустить `SpringBootLab8Application` и открыть http://localhost:8080/.
Таблицы `users`, `roles`, `users_roles`, `students` Hibernate создаёт сам при первом запуске.

## Доступ

| Страница | Кто может открыть |
|----------|-------------------|
| `/`, `/login`, `/register` | все |
| `/list`, добавление и изменение студентов | вошедшие пользователи |
| `/users`, удаление студентов | только `ROLE_ADMIN` |

Первый зарегистрированный пользователь получает роль `ROLE_ADMIN`, остальные – `ROLE_USER`.
Пароли хранятся в виде хеша BCrypt.
